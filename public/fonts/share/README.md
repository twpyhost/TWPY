Geist Regular is copied unchanged from the installed Next.js `@vercel/og` renderer.
Upstream: https://github.com/vercel/geist-font
License: SIL Open Font License 1.1; see OFL.txt (official upstream copy).

This 125,956-byte local font keeps the card templates below the 400 KB asset target.
Cards use a text TWPY wordmark and never load player avatars. The repository's
Warsaw font has no verified redistribution license record, so it is not bundled
into these card templates. Very long labels use a visible ellipsis; full records
remain available on the source page.

The font's Unicode cmap is checked before rendering. Unsupported graphemes and
emoji use `?` in card images, preventing the renderer from loading remote fonts
or emoji assets. Public names on the website are preserved in full.
